Understanding the Metrics¶

Preliminary Concepts¶

Before diving into the metrics, let's establish the fundamental notation and concepts used throughout this documentation:

Notation

Concept Symbol Description
Model Score $S \in [0,1]$ A real valued score assigned to each entity by the predictor.
Model Prediction
Decision		 $\hat{Y} \in \{0, 1\}$ The binary decision assigned to a given entity (data point) by the model based on the score
True Outcome
Ground Truth		 $Y \in \{0, 1\}$ The actual, observed outcome for an entity.
Protected Attribute $A = \{a_1, a_2, ..., a_n\}$ A multi-valued variable that defines protected groups (e.g., race, gender, age). E.g., $gender = \{female, male, other\}$
Group $g(a_i)$ A specific subgroup defined by all entities that share the same value of the protected attribute(s). E.g., $gender = female$
Reference Group $g(a_r)$ The group that is used as a reference for calculating fairness metrics.
Labeled Positive $LP_g$ Number of entities in group $g$ that are labeled as positive.
Labeled Negative $LN_g$ Number of entities in group $g$ that are labeled as negative.
Predicted Positive $PP_g$ Number of entities in group $g$ for which the predicted decision is positive, i.e., $\hat{Y}=1$.
Total Predicted Positive $K = \sum_{A=a_1}^{A = a_n} PP_g(a_i)$ Total number of entities predicted positive across groups defined by $A$.
Predicted Negative $PN_g$ Number of entities in group $g$ for which the predicted decision is negative, i.e., $\hat{Y}=0$.
Prevalence $Prev_g = LP_g/|g| = Pr(Y=1|A=a_i)$ The fraction of entities in group $g$ that are labeled as positive.

Confusion Matrix

Aequitas calculates fairness metrics based on the confusion matrix for each group defined by protected attributes. The confusion matrix consists of four fundamental cells:

Cell Symbol Description
True Positive $TP_g$ The number of entities in group $g$ with $\hat{Y}=1$ and $Y=1$. These are correctly predicted positive cases.
True Negative $TN_g$ The number of entities in group $g$ with $\hat{Y}=0$ and $Y=0$. These are correctly predicted negative cases.
False Positive $FP_g$ The number of entities in group $g$ with $\hat{Y}=1$ and $Y=0$. These are incorrectly predicted as positive.
False Negative $FN_g$ The number of entities in group $g$ with $\hat{Y}=0$ and $Y=1$. These are incorrectly predicted as negative.

Note that for any group $g$, the total number of entities is $|g| = TP_g + TN_g + FP_g + FN_g$.

Bias Metrics¶

From the confusion matrix, we can calculate the following fairness metrics for each group:

Fairness Metric Notation Description
Statistical Parity
Predicted Prevalence		 $PPrev_g = PP_g/|g| = Pr(\hat{Y}=1 | A=a_i)$ The fraction of entities in group $g$ that were predicted as positive.
Predicted Positive Rate
 $PPR_g = PP_g/K = Pr(a=a_i|\hat{Y}=1)$ The fraction of all predicted positives that belong to group $g$.
False Discovery Rate
FDR Parity 		$FDR_g = FP_g/PP_g = Pr(Y=0|\hat{Y}=1, A=a_i)$ The fraction of all predicted positives that are actually negative in group $g$.
FOR Parity
False Omission Rate		 $FOR_g = FN_g/PN_g = Pr(Y=1|\hat{Y}=0, A=a_i)$ The fraction of all predicted negatives that are actually positive in group $g$.
Predictive Equality
False Positive Rate (FPR)		 $FPR_g = FP_g/LN_g = Pr(\hat{Y}=1|Y=0, A=a_i)$ The fraction of actual negatives that are incorrectly predicted as positive.
FNR Parity
False Negative Rate (FNR)		 $FNR_g = FN_g/LP_g = Pr(\hat{Y}=0|Y=1, A=a_i)$ The fraction of actual positives that are incorrectly predicted as negative.
Equal Opportunity
True Positive Rate (TPR)		 $TPR_g = TP_g / LP_g = Pr(Ỹ=1|Y=1, A=a_i)$ The fraction of actual positives that are correctly identified. Measures how well the model identifies positive cases.
TNR Parity
True Negative Rate (TNR)		 $TNR_g = TN_g/LN_g = Pr(Ỹ=0|Y=0, A=a_i)$ The fraction of actual negatives that are correctly identified. Measures how well the model identifies negative cases.
Precision Parity
Precision		 $Precision_g = TP_g / PP_g = Pr(Y=1|\hat{Y}=1, A=a_i)$ The fraction of predicted positives that are actually positive. Measures the reliability of positive predictions.

Fairness Threshold (Tau)¶

Aequitas uses a fairness threshold (tau, default 0.8) to determine whether a disparity ratio indicates fairness. A metric is considered fair if:

$$\tau \leq \text{disparity ratio} \leq \frac{1}{\tau}$$

For example, with $\tau = 0.8$, a disparity ratio between 0.8 and 1.25 is considered fair. This implements the "80% rule" commonly used in employment discrimination law (also known as the four-fifths rule).

The threshold can be customized based on your specific fairness requirements and regulatory context.
